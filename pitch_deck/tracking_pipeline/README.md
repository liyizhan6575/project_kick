# Real-time tracking pipeline — demo

The state-of-the-art computer-vision engine behind [Pitch Prism](../pitch_prism.pdf): it turns raw
broadcast footage into **per-frame pitch homography, player tracks and the ball, fully
automatically** — detection → keypoint calibration → tracking → matting, with no manual
chroma-keying, tagging or camera calibration. It was deployed live on **World Cup 2026**.

Closed source for now; this folder holds the demo materials.
